POFF RECEIPT 스테이션 · 맥북 + 아이패드 + 영수증 프린터

[준비물]
- 맥북, 아이패드, 80mm USB 영수증 프린터(엡손 TM-T83II 등), USB 케이블(+ 필요하면 USB-C 젠더)
- 맥북과 아이패드가 같은 와이파이에 연결되어 있어야 해요 (전시장 와이파이가 불안하면 휴대폰 핫스팟)

[처음 한 번만]
1. 프린터에 용지를 넣고 전원을 켠 뒤, USB로 맥북에 연결해요.
2. "1_프린터_등록.command"를 더블클릭해요.
   - "확인되지 않은 개발자" 경고가 뜨면: 파일을 우클릭 → 열기 → 열기
   - 처음 실행할 때 "명령어 라인 개발자 도구 설치"가 뜨면 설치를 눌러 주세요 (5~10분)
   - 맥 비밀번호를 물어보면 입력해요
3. 프린터에서 "POFF / PRINTER READY"가 나오면 등록 끝!

[전시할 때마다]
1. "2_POFF_시작.command"를 더블클릭해요. 창에 아이패드 주소가 나와요. (예: http://192.168.0.10:8080)
2. 아이패드 사파리에서 그 주소를 열어요.
   - 공유 버튼 → "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 열려요.
   - 설정 → 손쉬운 사용 → "사용법 유도 접근"을 켜면 관람객이 다른 앱으로 못 나가요.
3. 관람객이 질문에 답하면 영수증이 프린터에서 자동으로 나와요. 인쇄 창은 뜨지 않아요.
4. 전시 중에는 맥북의 그 창을 닫지 마세요. 맥북은 잠들지 않게 설정돼요.

[문제가 생기면]
- 영수증이 안 나오고 아이패드에 "프린터 연결을 확인해 주세요"가 뜨면:
  프린터 전원 · 용지 · USB를 확인하고, 맥북 창에 뜬 오류 메시지를 확인해요.
- 아이패드에서 주소가 안 열리면: 맥북과 아이패드가 같은 와이파이인지 확인해요.
  맥 시스템 설정 → 네트워크 → 방화벽이 켜져 있으면 python3 연결을 허용해 주세요.
- 프린터만 따로 시험하려면: 브라우저에서 주소 뒤에 /test 를 붙여 열어요.
- 장소를 옮겨 맥 주소가 바뀌면 창에 새로 나온 주소로 다시 열어요.


[업데이트] 영수증이 두 장 나와요
1) 긴 영수증: 오늘의 미션 · 시작 쪽 · 질문 → 관람객이 가져가요
2) 짧은 조각: 시간 · 미션 한 줄 · 번호 → "벽에 꽂아 주세요" (부스 벽에 꽂는 조각)

[업데이트] 58mm 용지 · 인쇄 폭 48mm (kiosk.html 의 PRINT_MM 값으로 조절)

[업데이트] 긴 영수증 아래에 답 적는 칸(5줄 + 적어 준 사람) 추가 · 질문 화면 새 디자인(그림 카드 · 진행 막대) · 휴대폰 꺼짐 화면 애니메이션

[업데이트] 질문 화면 메시지형(채팅) · 아이패드 세로 기준 · 답 칸은 점선 빈칸 하나
